# 仕事実績のまとめ

業務で担当してきたバックエンド開発の実績を、技術的な観点で整理したものです（新しい順）。
各プロジェクトについて、担当した PR の中から**コード変更量が最も大きかったもの**をピックアップして詳しく紹介しています（担当業務の全体ではありません）。

※ 守秘義務のため、社名・リポジトリ名・業務ドメインの詳細などは記載していません。

## プロジェクト A：業務システムのバックエンド API

- 担当：NestJS / TypeScript 製バックエンド API の開発・保守
- 期間：2020年11月〜2026年9月（2022年から本格的に参画）
- マージ済み PR：800件超、累計変更 約 +229k / -85k 行
- 立ち位置：同リポジトリの中核的な長期コントリビューター

| ピックアップ | 概要 |
| --- | --- |
| [NestJS / TypeORM / AWS SDK 大規模アップグレード](docs/nestjs-major-upgrade.md) | NestJS v7→v10、TypeORM 0.2→0.3、AWS SDK v2→v3 を一括で実施 |

## プロジェクト B：Web サービスのバックエンド API

- 担当：NestJS + TypeORM 製バックエンド API の新規構築から機能拡張まで
- 期間：2021年3月〜2022年10月
- マージ済みの機能 PR：約125件、追加約 2.3 万行・削除約 6,700 行（合計約 3 万行、lock ファイル除く）
