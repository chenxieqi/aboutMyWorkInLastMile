# 仕事実績のまとめ

業務で担当してきたバックエンド開発の実績を、技術的な観点で整理したものです（新しい順）。
各プロジェクトについて、担当した PR の中から**コード変更量が最も大きかったもの**をピックアップして詳しく紹介しています（担当業務の全体ではありません）。

※ 守秘義務のため、社名・リポジトリ名・業務ドメインの詳細などは記載していません。

## プロジェクト A：受発注プラットフォームのバックエンド API

- 担当：NestJS / TypeScript 製バックエンド API の開発・保守
- 期間：2020年11月〜2021年3月（立ち上げ期）、2022年11月〜2026年9月（本格参画）
- マージ済み PR：800件超、累計変更 約 +229k / -85k 行
- 立ち位置：同リポジトリの中核的な長期コントリビューター

### 担当内容の概要

| 時期 | フェーズ | 主な担当内容 |
| --- | --- | --- |
| 2020/11〜2021/03 | 立ち上げ期：基本 API の構築 | ディレクトリ構成の整備。会社・グループ・物件など中核エンティティの CRUD と画像アップロード。レポート機能、ユーザーアカウント関連 API |
| 2022/11〜2023/02 | 再参画：共通基盤とお知らせ・主力サービスの立ち上げ | 管理者権限の JWT 検証、例外フィルターの共通化、日付サービス。お知らせ機能（公開設定・既読管理）。主力サービスの注文機能（エンティティ設計・プラン API・注文 API）を立ち上げ、画像レスポンス・サムネイル・CSV ダウンロード・メール通知などを高頻度で改善 |
| 2023/03〜2023/06 | 管理画面・パートナー向け機能の構築 | 検索機能の拡充、管理画面のログイン・お知らせ・管理ユーザー管理。ユーザー無効化。プラン紐付け、ページネーション、注文管理。パートナー（協力会社）向け機能の立ち上げ。会社・グループ階層の管理 |
| 2023/06〜2023/12 | 注文・決済・ベンダー基盤の拡充 | 画像の一括削除・CSV インポート。新サービス（清掃等）モジュールの追加。決済・フィードバック・キャンセルポリシー・オプションの仕組み。複数サービス展開に向けたサービス種別の体系化。ベンダー（外部委託先）のデータモデルと組織構造の設計 |
| 2024/01〜2024/10 | サービス種別の統一と機能拡張 | 注文種別・検索 ID の統一リファクタリング、ベンダー概念の命名統一。トライアルチケット。カタログ機能（アイテム・部屋タイプ・スタイル等）。決済の作成/更新、納品制限。顧客向けお知らせ。立会人管理とメール通知の横断対応。パートナー側の IP 制限 |
| 2024/11〜2024/12 | フレームワークの大規模アップグレード | NestJS v7→v10、TypeORM 0.2→0.3、AWS SDK v2→v3 を一括実施（[詳細](docs/nestjs-major-upgrade.md)） |
| 2025 | キャンセル・通知・ベンダー支払い基盤・新サービス | サービスごとのキャンセル種別とパートナー報酬。前払いチケットの管理。取引先別メールのカスタマイズ。通知 API の統一。ベンダー支払いテーブルの新設。出張型サービスの画像アップロード/ダウンロード一式。パートナーのパスワード再設定、予約可能日のルール整備。ペット情報の追加と CSV 出力。郵便番号 API 連携。MySQL ドライバ等のライブラリ更新 |
| 2026 | 新サービス種別の追加と決済基盤の全面再設計 | AI 画像機能の連携。サービス種別ごとの組織設定、選択不可日の管理。新サービス種別 2 つの追加と取引先別 CSV・プランオプション・エリア・キャンセル権限など。決済・ベンダー支払い（明細含む4テーブル）の再設計を段階的に実施し、金額計算・承認フロー・PDF 生成などを安定化 |

## プロジェクト B：Web サービスのバックエンド API

- 担当：NestJS + TypeORM 製バックエンド API の新規構築から機能拡張まで
- 期間：2021年3月〜2022年10月
- マージ済みの機能 PR：約125件、追加約 2.3 万行・削除約 6,700 行（合計約 3 万行、lock ファイル除く）

### 担当内容の概要

| 時期 | フェーズ | 主な担当内容 |
| --- | --- | --- |
| 2021/03〜2021/07 | 新 API の基盤構築・旧システムからの移行 | 共通層（Entity / Service / Repository のベースクラス、ページネーション、統一レスポンス、Migration / Factory / Seed）の構築。AWS Cognito による認証（登録・メール認証・ログイン/ログアウト・トークン更新・JWT 検証）。ユーザー・お気に入り・フォロー・ロール・ゲスト等の業務 API 約20本。AWS SES によるメール送信。CircleCI 導入、Swagger 整備、テストコード追加 |
| 2021/10〜2022/02 | サービスのリニューアル | ワークスペース機能の API（CRUD、テスト、Swagger）。多言語対応（i18n）。Migration の整理。S3 アップロード API。チケット機能の API。Apple 等のソーシャルログイン、リフレッシュガード、ログアウト。権限・検索 SQL・ページネーション等の不具合修正 |
| 2022/03〜2022/06 | 管理画面向け API | お知らせ・お問い合わせ・ユーザー・チケットの管理 API。ワークスペースのアカウント・割引・ストレージ容量・料金プランの管理。コンテンツの公開状態・複数条件検索・匿名設定・削除済みデータの管理。データ容量の再計算、アプリのバージョン管理 API |
| 2022/07〜2022/10 | 機能拡張・改善 | おすすめ表示の管理機能（テーブル設計〜管理 API）。LP（ランディングページ）向け API 一式と継続改善。一部機能の DynamoDB への移行。不具合修正、テストコード追加 |
